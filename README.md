# recipe-app
выполнил: Трофимов Михаил Олегович

## Библиотека Рецептов (Vanilla JS)
Проект выполнен в рамках семестровой работы.

## Функционал
- Вход по имени пользователя.
- Загрузка данных из Spoonacular API.
- Фильтрация по диетам.
- Сортировка по времени приготовления (State management).
- Расчет статистики (среднее время готовки).

## Технологии
- JavaScript (ES6+), ООП, Модули.
- HTML5/CSS3 (Flexbox/Grid).
- Асинхронные запросы (Fetch API).
